# JavaBeans Color Preferences

A Java web application demonstrating JavaBeans and JSP.

## Features

- JavaBean getters and setters
- Foreground and background color customization
- Request scope
- Session scope
- Application scope
- Default color handling
- Whitespace validation
- JSP Expression Language

## Technologies

- Java 8
- JSP
- JavaBeans
- HTML
- CSS
- Apache Tomcat 7
- Eclipse Mars
